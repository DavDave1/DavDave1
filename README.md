## Selected projects

### [Horus](https://github.com/DavDave1/horus) · C++

An experimental x86-64 operating system with a custom UEFI bootloader and monolithic kernel. I built it to explore how boot, virtual memory, interrupts, and memory allocation fit together.

### [GB-R](https://github.com/DavDave1/gb-r) · Rust

A Game Boy emulator with a debugger that lets you disassemble instructions, set breakpoints, and inspect CPU and graphics state.

### [RetroHunter](https://github.com/DavDave1/RetroHunter) · C# / Avalonia

A Windows and Linux desktop app that matches your ROMs against RetroAchievements hashes and organizes compatible sets for EmuDeck. The UI takes its cues from Windows 98.

### [Pokémon Agents](https://github.com/DavDave1/herdr-pokeon-agents) · JavaScript

A Herdr mod that gives your coding agents a pixel-art habitat. Agents roam through procedurally generated forests, deserts, caves, and mountains. Select an avatar to jump to its agent.

### [Librarian](https://github.com/DavDave1/Librarian) · C# / .NET MAUI

Shows the architecture of a reading tracker through an arc42 design document.
